# Sky cultures

These folders are **unmodified copies** of sky cultures from
[Stellarium](https://github.com/Stellarium/stellarium/tree/e84ca6da77de85dd73093ca8fe98e37c849e6ad3/skycultures),
taken at commit `e84ca6da77de85dd73093ca8fe98e37c849e6ad3`. Each file's SHA-256 is checked by the
data pipeline (`histeclipse-pipeline skycultures`). The web app reads them as they are and draws
them; nothing here is edited or converted.
